# Badminton Taktikboard

Ein lokales Badminton-Taktikboard zum Verschieben von Spielern und Shuttle, Zeichnen von Laufwegen, Verschieben und Löschen von Pfeilen sowie Festhalten taktischer Notizen.

## Lokal starten

```powershell
node server.js
```

Danach im Browser öffnen:

```text
http://127.0.0.1:5173/
```

Für GitHub Pages werden nur `index.html`, `styles.css`, `app.js` und der Ordner `assets` benötigt.
